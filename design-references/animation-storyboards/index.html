How to read these storyboards

Each frame is one moment of the animation. Under every frame, Maths state says what is mathematically true on screen, and Motion says how the picture gets there. Motion is a transition only; it never adds or changes a value.

Teal tile: the value in use during this beat
Solid teal line: a real calculation between two values
Dashed purple arrow: a value travelling to its next place (motion only)
Lavender chip: a deviation, base − number
Amber token: a carry or borrow, always visible while it waits
Dashed outline: an empty slot, or where a moving value came from
